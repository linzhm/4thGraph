## Measurements

The universal lock is 22,780 bytes. An ordinary BIP143 unlock is 8,357 bytes
and an unpaired OTDA SINGLE unlock is 8,361 bytes. Universal lock plus
ordinary BIP143 unlock totals 31,137 bytes (30.41 KiB). The legacy lock
and unlock remain 22,491 and 8,355 bytes.

Thirty warm samples on macOS arm64 / Python 3.12.16 gave median chain-gang
complete-transaction verification of 0.319 ms for universal BIP143 ALL and
0.363 ms for unpaired OTDA SINGLE with ANYONECANPAY. Local timing, the legacy
stack observation, and opcode counts are in [measurement.json](../template/measurement.json).

## Reproduction

Use the commands in the [project README](../README.md). For R1 regression together
with the Lamport node tests, install both projects’ dependencies in `.venv` and run from the repository root.

```sh
PATH="$PWD/.venv/bin:$PATH" PYTHONPATH="$PWD/projects/p2pkh-r1/reference" LAMPORT_RPC_PORT=18443 \
  bash projects/lamport-ots/reference/verify_apple.sh test_payment
```

The SM2 regression results above were recorded in a separate local workspace.
The GitHub workflow is manual only. When dispatched, it repeats the Lamport
checks with a Linux BSV Node release build and uploads benchmark output.
