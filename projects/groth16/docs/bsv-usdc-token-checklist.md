# BSV 代币协议实现清单

版本 0.1 · 2026-11-24

对应 [桥接资产协议规格](bsv-usdc-bridge-spec.md)。「部分」表示已有原型证据，该条规格仍有验收缺口。

| 规格 | 代币协议需支持的能力 | 当前状态及剩余工作 |
|---|---|---|
| R01 | 资产描述符、持有人、数量、冻结状态与版本 | **部分。** 已有发行 outpoint、uint64 数量、持有人公钥和模板匹配。新增域、精度、活跃／冻结、版本编码和取值检查。 |
| R02 | 跨链入金证明解析与认证 | **待实现。** 固定 1,024 枚用例使用本地锚点。新增测试入金适配器、消息解析、签发者、金额、收款人和确认检查。 |
| R03 | 可重复接收新入金，一笔入金只铸造一次 | **部分。** 有一次性发行锚点。新增持续铸造、原子防重放与额度授权。测试并发提交和重复签发。 |
| R04 | 绑定真实交易和来源的 MIMO 证明 | **部分。** 已有真实 Groth16、共享验证器、紧凑摘要电路、MIMO 算术电路及递归参考模型。须在同一证明内绑定真实输入父交易、前序证明、金额槽位、真实输出及后继锁。 |
| R05 | 冻结／解冻、保持金额及所有权 | **待实现。** 已有设计。增加锁定分支和发行人授权，逐个绑定互异的后继输出，覆盖错钥、改量、换持有人和竞态。 |
| R06 | 分操作暂停和可选地址政策 | **待实现。** 先定义铸造和释放暂停。持续地址封锁及全局转账暂停由 X03 确定后落实，包含策略新鲜度证明。 |
| R07 | 绑定目的域与收款人的全额及部分销毁 | **待实现。** 扩展正常守恒路径，约束销毁额、找零及唯一赎回事件。 |
| R08 | 基于确认销毁的一次性源链释放 | **待实现。** 新增源链适配器和原子结清记录。支持原请求重试，拒绝假事件和重复兑付。 |
| R09 | 可被对账的供应及储备记录 | **待实现。** 定义铸造、销毁和释放事件接口。外部账本按域对账、解释在途和费用，并触发异常流程。 |
| R10 | 可重建的确认、重组及故障状态 | **待实现。** 增加状态接口、补扫及幂等请求。同源重复、乱序、回滚和重启应有测试。 |
| R11 | 最小权限和可验证的版本迁移 | **部分。** 有验证器描述符。新增角色、轮换及撤权、旧证明处理、旧 UTXO 迁移及权限测试。 |
| R12 | 钱包按 vout 独立验收与状态查询 | **部分。** 钱包工具可比对完整锁、核对实际引用的前序输出。接入铸造、正常转移及行政路径的确认凭据，另提供已知花费状况。 |
| R13 | 真实代币闭环与独立节点验收 | **部分。** 已有 1,024 枚离线回归。跨链闭环、完整递归代币证明及 BSV Node 入块待验收。完整验收后安排独立审计和正式参数。 |
| R14 | 多输入容量和真实费用基准 | **部分。** 64→64、256→256 已在算术测试证明下跑通 chain-gang。完整代币证明接入后重测完整字节、出证、节点和钱包成本。 |

## 实现依赖

1. **确定资产及交易语句（R01、R04）。** 完成实际父输出、后继输出和摘要的绑定。冻结和销毁复用这层约束。
2. **建立合法铸造起点（R02、R03）。** 可与上一步并行定义测试消息和唯一铸造权。普通转移必须认得这一基例，并实际验证前序证明。
3. **补齐业务出口（R05、R07、R08）。** 执行冻结、解冻、销毁和一次性释放。暂停与地址政策按照 R06 和合作条件确定。
4. **验收而后主网准备（R09–R14）。** 接入运营和钱包，跑通 1,024 枚闭环及攻击性负例，并测 64 与 256 输入的成本。X01–X04 等待双方确认，独立测试桥可先进行。

证据入口：[交易与大小测试](transfer.md) · [出证工具链](toolchain.md) · [1,024 枚回归](regtest.md) · [冻结设计](issuer-freeze.md)。
